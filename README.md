# Jogo de Quiz em C++

Projeto desenvolvido em **C++** como parte da minha formação em Desenvolvimento de Software.

O objetivo do projeto foi aplicar conceitos fundamentais de programação através do desenvolvimento de um jogo de perguntas e respostas executado em console.

## Funcionalidades

- Seleção de nível de dificuldade
- Níveis Iniciante, Intermédio e Avançado
- Carregamento das perguntas através de ficheiros `.txt`
- Seleção e apresentação das perguntas durante o jogo
- Validação das respostas do utilizador
- Sistema de pontuação
- Registo de pontuações em ficheiro
- Utilização de perguntas aleatórias

## Tecnologias e conceitos utilizados

- C++
- Funções
- `struct`
- `vector`
- Strings
- Manipulação de ficheiros
- Validação de entradas
- Geração aleatória
- Lógica de programação

## Estrutura

- `main.cpp` — código-fonte principal
- `Iniciante.txt` — perguntas de nível iniciante
- `Intermedio.txt` — perguntas de nível intermédio
- `Avancado.txt` — perguntas de nível avançado
- `pontuacoes.txt` — armazenamento das pontuações

## Objetivo de aprendizagem

Este projeto permitiu colocar em prática conceitos estudados durante a formação, principalmente organização do código, manipulação de dados, leitura e escrita de ficheiros e resolução de problemas utilizando C++.
